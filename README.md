# Diabetes Data Analysis

This project focuses on analyzing the Diabetes dataset from Kaggle using Python.
The goal is to explore the data, perform cleaning, visualize trends, and build insights.

## Dataset
Source: https://www.kaggle.com/datasets/mathchi/diabetes-data-set

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

## Objectives
- Understand the structure of the dataset
- Perform exploratory data analysis (EDA)
- Visualize key patterns
- Draw insights related to diabetes prediction

## How to Run
1. Clone the repository  
2. Install requirements  
3. Open the notebook and run cells
